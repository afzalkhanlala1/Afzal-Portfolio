# Portfolio direction: personal workbench

User feedback supersedes the first redesign: restore the original warm palette, remove decorative dots/badges, reduce scrolling, separate pages, add playful and substantive interaction.

Palette: paper #F4F0E8, ink #24211D, vermilion #C9472D, moss #67715B, ochre #B9954B, rule #D2CABE. Dark mode uses warm charcoal #1D1B18 and parchment #EAE2D5.
Typography: original Instrument Serif display and IBM Plex Sans body. No capsule labels, generic status dots, rounded AI icon tiles or blue theme.
Layout: compact horizontal workspace with independent Home, Work, About, Experience, Research, Lab and Contact routes. Main content left-aligned; project collection paginated; detail pages use tabs.
